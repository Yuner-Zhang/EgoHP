# Official Project Aria Example

This directory contains a processed 20-second excerpt from
`AriaGen2PilotDataset_v1.0_play_0_main_recording.vrs`.

The example was generated by the EgoHP pipeline using the official published
MPS result supplied through `--mps-dir`. No VRS was uploaded to Meta MPS during
this run.

```text
converted/
|-- collectors.json
|-- recording_index.json
`-- Indoor/
    `-- living_room/
        `-- seq_official_sample/
            |-- seq_official_sample.mp4
            |-- frame_labels_vis.mp4
            |-- imu_left.txt
            |-- imu_right.txt
            |-- trajectory.txt
            |-- metadata.json
            |-- frame_labels.json
            `-- temporal_labels.json
```

The excerpt contains the first 200 RGB frames at 10 FPS. Person annotations
were generated with YOLO Pose, BoT-SORT, and screen filtering. Temporal labels
use the official closed-loop trajectory, IMU, calibration, and semidense MPS
geometry.

The original VRS and `mps/` directory are intentionally excluded because they
are too large for Git. The MP4, TXT, and JSON files are direct outputs of the
same pipeline used for complete sequences. `frame_labels_vis.mp4` is included
for visual annotation review. Paths to the omitted VRS are retained in
`recording_index.json` to demonstrate the full dataset mapping schema.

Validation summary for this generated excerpt:

- 200 RGB frames covering 19.90 seconds.
- 548 person boxes across three sequence-local identities.
- No missing per-person occlusion labels.
- Seven adaptive temporal segments.
- No `null` relative-motion or camera-motion labels.
- One person-segment has `person_distance_m: null` because too few reliable MPS
  points project into that bbox.

The processing run used the equivalent of:

```bash
python tools/prepare_data.py \
  --vrs /path/to/raw/0/AriaGen2PilotDataset_v1.0_play_0_main_recording.vrs \
  --dataset-root /path/to/example_output \
  --sequence-id seq_official_sample \
  --mps-dir /path/to/official/mps \
  --max-video-frames 200 \
  --min-track-hits 20 \
  --cpu-decode \
  --no-keep-mps
```

Detector model paths and device selection are omitted from the example command
because they depend on the local installation.
